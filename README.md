## Analytical Approach

Across these projects, I apply a structured analytical process:

1. **Understand the problem:** Identify the objectives and questions the analysis should address.
2. **Explore the data:** Examine available fields, relationships and potential data-quality issues.
3. **Prepare the data:** Clean and organise datasets for analysis.
4. **Analyse:** Apply appropriate spreadsheet, SQL or Power BI techniques.
5. **Visualise:** Present findings through tables, charts and dashboards.
6. **Communicate insights:** Explain the results, limitations and implications.
